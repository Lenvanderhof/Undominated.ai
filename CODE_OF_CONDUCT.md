# Code of conduct

This tracker exists so a wrong price, score, or rank can be corrected in public. That only works if people can file a disagreement without being shouted at.

## Expected

- Corrections come with a **primary source** (vendor page, official dataset, dated snapshot) and a date you checked.
- Disagreement is about a figure, not a person.
- Unrated is not zero. Missing is not free. Unknown is not a win.

## Not welcome

- Scraped or paywalled catalogues dumped into an issue.
- Artificial Analysis extracts. We cannot redistribute them and we will not host them here.
- Harassment, pile-ons, or “gotcha” campaigns that skip the source URL.

## Enforcement

The maintainer ([Len van der Hof](https://lenvanderhof.com)) may hide, lock, or delete a thread that is a dump, a sublicence request we cannot grant, or an attack. Security issues go to [advisories](https://github.com/Lenvanderhof/Undominated.ai/security/advisories/new), not a public issue.

This is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The product rule underneath it is the same as the site: **never publish a number you cannot trace.**
